# Prueba humana futura

Este paquete es investigación: no instalar sus C++ como mod. Continúa disponible el baseline 0.5.1; ningún resultado nuevo habilita una prueba de gameplay con EOC2 escrito.

Cuando exista una candidata que supere contactos/ABI/CI: A) probar sin Expansion con Blue y Red nativo; B) ocho mods, Blue solo/grupo, Red normal/especial y Black normal/furia por separado; C) sesiones prolongadas, cambios de sala y generaciones. Instalar una sola versión del ID dev.posture.post05_selective_reactions, conservar 0.5.1 para volver atrás.

Por caso anotar: momento/evento, B/C recién arrancado o maduro, continuidad del ataque, velocidad, guardia, contacto efectivo a Link, daño/chip y posible curación Red. SUPPRESSION_APPLIED prueba tres escrituras y readback, no continuidad visual ni daño correcto. Preguntas: ¿terminó el ataque sin reiniciarlo?, ¿hubo un segundo contacto o chip con el mismo golpe?, ¿x2 se mantuvo?, ¿se conserva rebote de escudo?, ¿la curación corresponde a un único golpe efectivo?

STOP: crash, doble daño/curación, rate/frame desincronizado, cadena infinita, escudo/chip incorrecto, HP incoherente, audio ausente, caída severa de FPS, conservación!=1 o hook/ABI discrepante. Retirar candidata con juego cerrado y volver a 0.5.1. A postura100 el cuarto golpe y los posteriores siguen nativos: el latch es intencional; POST06 físico no se inició.
