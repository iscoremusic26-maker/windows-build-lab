# Instalación y QA Windows/DX12
1. Cierre Dusklight; respalde saves y los JSON de ambos mods. Conserve fuera de mods el proveedor0.7.4 y Expansion0.1.0 anteriores. No cambie EXE, SDK o ROM.
2. Descomprima el ZIP privado verificado. Instale SOLO DEVF_Provider_0.8.0_TEST.dusk + BokoblinExpansion_0.2.0_TEST.dusk. Retire probe y otras versiones DEVF. Mantenga el placements.json del proveedor en NONE para disponer de ocho slots; no borre sus encuentros de diseño. El editor no escribe esos archivos.
3. Abra DEVF Map Editor.exe. Importe su R03_00.arc de F_SP121 mediante el selector; no hace falta enviarlo ni copiarlo al mod. Si el hash no corresponde, el editor rechaza el mapa: no se admite una calibración ficticia.
4. Elija Añadir y haga clic en puntos con apoyo estático válido. Cree inicialmente TRES marcadores separados; seleccione/mueva con arrastre, duplique eligiendo otro punto, edite yaw/activación o elimine. Rueda=zoom; botón derecho=desplazar. Rojo/no colocable no se exporta como suelo seguro.
5. Seleccione la carpeta de datos del consumidor de SU instalación. Referencia habitual: `%APPDATA%\\TwilitRealm\\Dusklight\\mod_data\\dev.bokoblin.expansion`. Guarde como encounters.json. La ruta runtime se obtiene por HostService.data_dir; no es la carpeta mods. Sobrescritura requiere confirmación, respaldo verificado y detección de cambios externos. El ejemplo encounters.json está vacío por seguridad; static-candidates-QA.json contiene puntos derivados para revisión, nunca activación automática.
6. Inicie el EXE oficial con el botón o normalmente; DX12. Recorra esa región de F_SP121/3/6 y confirme presencia/terreno de los tres adicionales. Los logs identifican solicitudes y tickets, nunca ActorId de placement. Cierre por completo antes de modificar el JSON.
7. Desactive/mueva un marcador, guarde y haga un nuevo arranque para comprobar que no requiere recompilación. No hay hot reload. Si aparece un error, duplicado, caída, bloqueo o actor mal situado, pare y conserve log/reporte.
8. Rollback en frío: retire ambos nuevos mods, restaure proveedor0.7.4 y Expansion0.1.0 y sus JSON respaldados. El nuevo encounters.json pertenece al consumidor0.2.0; el viejo0.1.0 usa qa.json. Remove_edit no destruye actores ya vivos.

El editor calcula geometría estática; Codex no ejecutó Dusklight. Apariciones, navegación, rendimiento Intel UHD y UX interactiva quedan HUMAN_RUNTIME_PENDING.
