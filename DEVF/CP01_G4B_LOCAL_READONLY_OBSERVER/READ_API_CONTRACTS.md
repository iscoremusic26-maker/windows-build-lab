* `dBgS::GroundCross` DEBUG wrapper at src/d/d_bg_s.cpp:1113 increments shared counters/timers. Use the explicitly qualified base method above; no host patch.
* `dBgS::SphChk` at :1347 can update DEBUG counters; `dBgWKCol::SphChk` at src/d/d_bg_w_kcol.cpp:2108 writes **static Vec vtx_tbl[3]** and invokes caller callbacks. Rejected. Exact local BG intersection: UNAVAILABLE_WITH_SAFE_API. No alternate hook.
* Water-group GroundCross is a vertical surface probe. No proven safe universal liquid-volume query here. NOT_VERIFIED absence of water throughout501; UNAVAILABLE_WITH_SAFE_API volume coverage. No hit is only NO_HIT_AT_PROBE.
* General native actor extent/physical overlap, BG universal transform and local coach/escort-specific state have no accredited interface in this implementation. UNAVAILABLE_WITH_SAFE_API / OVERLAP_NOT_VERIFIED. Do not infer them from centers, cull boxes, rooms or resource radius.
* Registered E_OC/E_ocb uses historical GetObjectResInfo only; REGISTERED != READY. No load/sync requested.
* LogService.write is the explicit bounded output exception: src/dusk/mods/svc/log.cpp -> log::emit copies message synchronously. This writes diagnostics, not gameplay state. No direct DLL file I/O; Host/Game services supply metadata/import binding only.
