## 3. Verification offered here
LAB (`strokes_lab`, 28 cases): the 19 CP10.6C cases adapted unchanged in intent, plus nominal geometry, placement/clamps/follow, local-translation compensation, direction lock rules, minimum-radius rule, alpha progression, readback honesty, inactive states and re-entry. Mutation checks (flip compensation sign, drop the min-radius rule, drop clamps, widen the direction lock, remove the compensation) are each caught. The reused labs (visual 22, eye 9, dynamic 28, damage 22, variant 30, runtime 66, black 26, texture 20, editor 42/71/110/25) run unchanged. A stub compile of the real `mod.cpp` aura path under ASan/UBSan was exercised locally. CI adds the MSVC build, the PE/ABI audit and the independent download check. **None of this executes the game or renders a pixel.**

## 4. Telemetry (`DEVF_CP10_6C_FIX01`, bounded: transitions only, <= 24 per actor, <= 400 per session)
`RESOURCE_PROBE` / `RESOURCE_FOUND` / `RESOURCE_MISSING` (<= 3 per id), `RESOURCE_GEOMETRY` (resource-local translation, direction, rotation flag, min radius, volume size), `CURVE_PROBE` (KEY_TABLE_READ_ONLY: id, loop, count, first and last time/value of the two curves, `last_positive`; and one LIVE_EMITTER_READ_ONLY sample of the emitter's own `mRate`/`mLifeTime` after 90 emitter ticks), `ACTOR_STATE_ON/OFF`, `REQUESTED`, `EMITTER_ACQUIRED/REJECTED/RELEASED`, `COLOR_APPLIED/UNAVAILABLE`, `TUNING_APPLIED` (per created emitter: resource, variant, encounter, generation, key, `y_off`, `radius_nominal`, `radius_inner`, scales, `min_rad_applied` read back, compensation, direction decision, fade level and alpha, status = readback match or mismatch). The curve reads use inline getters of the loaded resource: no import, no write, no asset I/O; if a table cannot be read the line says `CURVE_END_UNVERIFIED`. No pointers, no dumps.

## 5. Limits
Everything about *appearance* is pending the human round; the nominal sizes are not rendered sizes; the resource's scale animation (`scale_anim=1`), colour animation and curve end values are not modelled; the effect is still one of the original three emitters (A+B+C); the shared pool, cutscenes and other mods are unverified; the ring may now look too large or too faint. There is no `VISUAL_ACCEPTED` event and CI cannot create one.
