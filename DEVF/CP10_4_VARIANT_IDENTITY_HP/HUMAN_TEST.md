1. Close the game. Back up `BokoblinExpansion_0.5.0_TEST.dusk` and `encounters.json`. Put ONLY `BokoblinExpansion_0.6.0_TEST.dusk` in its place; keep provider 0.10.0, the editor and your JSON.
2. **Native `E_OC`** (not placed by DEVF): wound it without killing it. The log must show `DEVF_CP10_4_VARIANT event=VARIANT_ADMITTED ... source=NATIVE_E_OC classified_variant=BLUE native_base_hp=40 hp_before=40 hp_after=220 effective_max_hp=220 regen_rate_hp_s=2` and, while it heals, `REGEN_APPLIED kind=BLUE` about every 150 ticks per 10 HP. If you do not know which scene has one, play normally and read the log: it names every native Bokoblin type it meets.
3. **Native `E_OC2`** (not placed by DEVF): same check; expect `source=NATIVE_E_OC2 classified_variant=RED native_base_hp=220 hp_after=330 effective_max_hp=330 regen_rate_hp_s=3` and `REGEN_APPLIED` about every 100 ticks per 10 HP. Do not confuse it with step 4.
4. **DEVF Normal** (`bokoblin-001/002/003`, F_SP121 / room 3 / layer 6): expect `source=DEVF_NORMAL classified_variant=BLUE hp_after=220 regen_rate_hp_s=2` (it is an E_OC2 resource, so it keeps that look).
5. **Black** `bokoblin-004` with your JSON unchanged (`hp 150`): `source=DEVF_BLACK classified_variant=BLACK effective_max_hp=150 regen_rate_hp_s=4`, approved texture, `HP_APPLIED` as before. Then, only if you accept the balance value: with the game closed use the CP10.2 editor (select bokoblin-004, HP = 440, Install; it keeps a verified backup) or edit that single `"hp": 150` to `"hp": 440` in a copy of the JSON, restart, and expect `effective_max_hp=440`. Report 440 only if you did this second run.
6. Wound without killing and check the cap and the healing lines; kill one of each kind: it must stay dead. Optional: pause/re-enter a room.
7. Rollback: restore 0.5.0 and your backed-up JSON; never keep both Expansion files. Send only the `DEVF_CP10_4_VARIANT`, `DEVF_CP10_3_REGEN` and `DEVF_CP10_2_BLACK event=HP_APPLIED` lines.
